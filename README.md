## Overview
K-Ray is a small business that makes handmade hair clips, bows and accessories. I built the website so customers could see the whole catalog in one place and order without needing a full online store. The site is in Spanish, since it's made for customers in Peru.

---

## Features
| | |
|---|---|
| 🛍️ **Product catalog** | Organized by collection: clips & accessories, Hello Kitty and Friends, Labubu accessories and Labubu clothing |
| 💬 **Order via WhatsApp** | Every **Comprar** button opens WhatsApp with a message that already names the product |
| 🎠 **Carousels** | An auto-playing hero carousel and product rows with arrows that adapt to the screen width |
| 📱 **Responsive** | Mobile-first layout with a hamburger menu |
| 📍 **Store info** | About us section and the shop's location with a Google Maps link |

---

## 🛠️ Tech Stack
- **HTML5, CSS3 & vanilla JavaScript.** No frameworks.
- **WhatsApp click-to-chat** (`wa.me`) with pre-filled messages
- **Hosting:** GitHub Pages

### Project structure
```
K-Ray/
├── index.html     # Catalog page
├── style.css      # Layout & styling
├── carousel.js    # Carousels, WhatsApp links, mobile menu
├── img/           # Product photos & icons
└── sitemap.xml
```

### Run locally
```bash
git clone https://github.com/alex-gamero/K-Ray.git
cd K-Ray
# open index.html in your browser
```
